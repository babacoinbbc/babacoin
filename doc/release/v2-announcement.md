# Babacoin V2 is available

Babacoin V2 improves wallet usability, startup and rescan visibility, Windows
installation and platform compatibility. Optional Explorer peer discovery and
blockchain bootstrap downloads help users connect and synchronize.

**Mandatory upgrade:** wallets, exchanges, pools and validating nodes must
upgrade before the first 2,000,000 BBC Smartnode registration. Early registration
is available; 1,800,000 BBC collateral stops qualifying for rewards at block
**1,250,000**.

Back up your wallet before upgrading. The existing Babacoin mainnet continues.

[Download V2 and bootstrap files](https://github.com/babacoinbbc/babacoin/releases/latest)
