# Babacoin Core V2.0.3 — Mainnet

Release tag: `v2.0.3`. Application version: `2.0.3.0`.
Use `RELEASE-MANIFEST.json`, `SHA256SUMS` and the individual checksum files to
identify the exact source and packages. The wire protocol remains 70219;
application and protocol version numbers serve different purposes.

Linux builds made from the CI source snapshot now retain that snapshot's actual
commit in `buildversion`. Exported source archives also receive their own Git
commit identity instead of the inherited 2022 identifier. Native smoke tests
check runtime version, user agent and CI commit identity before packaging.

## Desktop responsiveness and accessibility

Periodic balance calculations now run outside the GUI thread. Work is coalesced
and outdated results are discarded after newer wallet notifications. This
addresses a source of stalls in large transaction histories while retaining
normal transaction validation. It is not a guarantee that disk access, scans
or every explicit wallet operation will finish instantly.

Windows/macOS navigation and dashboard layouts adapt to short/narrow windows
and larger fonts. Bottom navigation stays reachable, cards can stack, and
hidden forms no longer force the current page to expand. The Smartnode setup
wizard uses readable themed headings and scrollable content. Its eligibility,
fee, signing and explicit registration-consent checks remain in place.

About links to the official Babacoin repository and retains the upstream
license attributions without showing the same inherited line twice. Full
license text remains accessible by scrolling. Open-source Qt 5 is retained;
this is not a Qt 6 migration.

V2.0.2's moved-data-folder recovery remains available. Startup/rescan progress,
day/night themes, localized amounts, optional Explorer discovery and the Web
Wallet browser-launch tab are retained. Replacing a wallet file can require a
local scan even when the blockchain itself is synchronized.

## Easy Linux setup and updates

For Ubuntu 18.04/20.04/22.04/24.04/26.04 or Debian 12/13 on x86_64/aarch64:

```bash
curl -fL --proto '=https' --proto-redir '=https' \
  https://raw.githubusercontent.com/babacoinbbc/babacoin/main/install-node.sh \
  -o install-node.sh && bash install-node.sh
```

The tool detects the supported OS/architecture, installs matching dependencies,
verifies the latest stable release and upgrades an identified running daemon
using its existing account, data and arguments. It backs up wallet/configuration
files after normal shutdown and creates start/stop/CLI launchers. No periodic
updater or new boot service is silently installed; rerun the command to update.
Smartnode funding, keys and registration remain separate explicit operations.

Bootstrap defaults to `auto`: a new data directory downloads and verifies the
full archive; existing chain directories or bootstrap input/completion files
are preserved. On a shared filesystem, staging checks count the ZIP and both
simultaneous payload copies before bootstrap download or daemon shutdown.
The installer never removes wallets or chain data to free space. See
`LINUX-NODE-SETUP.md` for custom paths, support limits and recovery instructions.

## Packages and installation

Windows users can run `babacoin-v2.0.3-windows-x86_64-setup.exe`; it includes
the tested DLLs and Qt plugins. Portable users must keep the complete extracted
directory together. Windows 11 ARM64 uses the same x64 application under tested
emulation, not a native Windows ARM64 executable.

Choose the macOS Intel or Apple Silicon archive matching your computer. The GUI
is bundled and ad hoc signed. Native build/test coverage is macOS 15; Apple
Developer ID signing and notarization are not supplied. Bundled-app checks
verify local library paths, signatures, version, isolated startup and restart.
Transitive Homebrew dependencies, including Boost's sibling libraries, are
copied recursively and rewritten to existing files inside the app. A Mac does
not need the build machine's Homebrew installation to provide those GUI files.

Linux packages require their matching distribution's runtime libraries. The
automatic setup handles these for the headless full node; it does not install
the Qt desktop. Do not mix Ubuntu/Debian ABIs or symlink incompatible libraries.
Raspberry Pi OS 64-bit uses the matching Debian ARM64 package. Physical Pi and
32-bit systems are not certified. See `PLATFORM-SUPPORT.md`.

**Windows security notice:** a v2.0.1 installer download was previously reported
as `Program:Win32/Contebrew.A!ml` by Microsoft Defender. Local scans did not
reproduce that result, but no Microsoft false-positive determination has been
received. New builds and functional tests are not malware-classification
clearance. Follow security-product warnings; do not disable protection, add
exclusions or restore quarantined files to run Babacoin. Portable packages are
not a security workaround.

## Bootstrap snapshot

The existing full bootstrap ends at block **1,062,893**. The raw archives are
reused unchanged; this is not a newer synchronized snapshot. The incremental
archive starts at **762,578** and requires the exact base block **762,577**.
The manifest and validation report describe provenance and the tested sample.
A 1,000-block sample import is not independent replay of the entire archive.

After clean shutdown, extract `bootstrap.dat` into the active mainnet data
folder, or use an explicit `-loadblock` path. Normal consensus validation still
runs, followed by peer synchronization for newer blocks. File-read completion
or a `.old` filename alone does not prove that block validation has completed.

## Network and wallet preservation

This maintenance release adds no consensus, collateral, key-format or mainnet
identity change. The existing V2 transition remains: all validators must
upgrade before the first 2,000,000 BBC Smartnode registration. Registration has
no opening block; V1 can reject its first block. The 1,800,000 BBC tier ends
reward eligibility at block **1,250,000**. Read `NETWORK-UPGRADE.md`.

Back up your wallet and close the old application cleanly before updating.
Install new program files without replacing `wallet.dat`. Installation does
not spend collateral, register a Smartnode, submit a spork or remotely upgrade
other participants. Check the running version with `getnetworkinfo` after
restart. No release guarantees defect-free software.
