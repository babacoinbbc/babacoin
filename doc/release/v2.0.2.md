# Babacoin Core V2.0.2 — Mainnet

Release tag: `v2.0.2`. Application version: `2.0.2`.
Use the source commit and SHA-256 checksums in `RELEASE-MANIFEST.json` to
identify these newly compiled packages. Updating a release label does not
update a previously downloaded executable.

## Moved or disconnected wallet data

The desktop now opens a recovery chooser when its saved data folder or a
shortcut's explicit `-datadir` location is unavailable. Reconnect the drive
and choose **Check again**, or locate the existing data folder and choose
**Use this folder**. Select the folder, not the wallet.dat file.

The selection is remembered for the current desktop user, including old
shortcuts that still specify the unavailable location. If that original
location returns, the desktop asks which existing wallet folder to use
instead of silently switching to an old copy. The shortcut itself is not
rewritten. Cancel leaves the location unchanged.

Recovery does not move, delete or repair files. Missing and empty folders
are rejected to avoid creating an unexpected empty wallet. The standard
wallet.dat must be present in the selected data folder, or in its wallets/
subfolder when that directory exists. Explicit relative -wallet selections
are recognized. For a custom wallet name configured only in babacoin.conf,
update the shortcut's -datadir path directly if necessary. The daemon's
strict command-line directory behavior is unchanged.

All V2.0.1 responsiveness, import-progress, day/night, localized-amount,
optional Explorer discovery, Smartnode wizard and Web Wallet features remain.
This maintenance release adds no consensus, collateral, key-format or
mainnet-identity change.

## Packages and runtime libraries

Windows: the setup wizard includes the DLLs and Qt plugins. Keep every file
and subfolder together when using the portable archive. Windows 11 ARM64
uses the tested x64 application under emulation; it is not a native ARM64
Windows binary.

**Windows security notice:** the previous v2.0.1 installer download was
reported as `Program:Win32/Contebrew.A!ml` by Microsoft Defender. A local
custom scan of that identical file did not reproduce the detection, but no
Microsoft false-positive determination has been received. This rebuild and
functional tests are not malware-classification clearance. Follow your
security product's warnings; do not disable protection, add exclusions or
restore a quarantined file to run Babacoin. A portable archive is not a
security workaround.

Use the package matching your macOS architecture or Linux distribution and
architecture. Ubuntu LTS 18.04–26.04 and Debian 12/13 have separate packages.
Raspberry Pi OS 64-bit uses the corresponding Debian ARM64 package; physical
Pi hardware and 32-bit systems are not certified. See `PLATFORM-SUPPORT.md`.

Linux archives are dynamically linked and require distribution runtime
libraries. For the **Ubuntu 20.04 package**, including ARM64, install:

```sh
sudo apt-get update
sudo apt-get install --no-install-recommends \
  libboost-filesystem1.71.0 libboost-program-options1.71.0 \
  libboost-thread1.71.0 libboost-chrono1.71.0 \
  libevent-2.1-7 libevent-pthreads-2.1-7 \
  libssl1.1 libzmq5 libminiupnpc17 libstdc++6
```

These package names are specific to Ubuntu 20.04. Qt desktop packages also
need their matching Qt/display libraries. Consult `RUNTIME-LIBRARIES.txt`
inside the selected archive. Do not symlink incompatible Boost/OpenSSL
versions or mix distribution packages. A missing shared library occurs
before wallet loading and does not require deleting or rebuilding wallet data.

## Bootstrap

The existing full bootstrap snapshot ends at block **1,062,893**. Its raw
blocks are unchanged; it is not a newly synchronized snapshot. The incremental
archive starts at **762,578** and requires the exact base block **762,577**.
Check the bootstrap manifest, checksums and included instructions first.

After a clean shutdown, place extracted bootstrap.dat in the active mainnet
data folder for automatic import, or use an explicit -loadblock path.
Normal consensus validation still runs. File-read completion and a .old
filename are not proof that validation completed. The recorded import sample
covers 1,000 blocks, not independent replay of the entire archive.

## Network upgrade and wallet preservation

The existing V2 transition remains: every validator must upgrade **before
the first 2,000,000 BBC Smartnode registration**. Registration has no opening
block. V1 can reject its first block. The 1,800,000 BBC collateral tier ends
reward eligibility at block **1,250,000**. See `NETWORK-UPGRADE.md`.

Back up your wallet before updating and close the old application cleanly.
Do not replace wallet.dat when installing new program files. Installation
does not spend collateral, register a Smartnode, submit a spork or remotely
upgrade other participants. No release guarantees defect-free software.

Release assembly requires the complete same-source platform matrix. The new
directory regression covers cancellation, empty-folder rejection, remembered
relocation, drive reconnection and the backend's default-wallet layout.
